# إيجاري — منظومة إدارة بيانات الإيجارات (نسخة العرض)

> المنتج عام: **كل ورقة/بيان يصل = «كشف» مستقل باسم مالكه** ضمن محفظة تكبر لآلاف الكشوف.
> «بيان عبدالمنعم سكرية» هو أول كشف فعلي فيها.

نسخة عرض كاملة الوظائف. المبنى الأول مبني **حصريًا** على الكشف الورقي المفرَّغ
(`Main received source data.xlsx` — بيان عبدالمنعم سكرية، تغطية يناير–يونيو 2026)،
ومعه **مبنيان توضيحيان** (برج النيل الإداري · مركز الحرية التجاري) ببيانات مولَّدة
لتجربة النظام كمحفظة متعددة الكشوف — يُحذفان بزر واحد من الإعدادات عند بدء الاستخدام الفعلي.

**المرشِّحات (السلايسرز)** أعلى كل شاشة: مبنى · نوع · مستأجر · حالة · بحث — تسري على كل الأرقام والرسوم.

## التشغيل

افتح `index.html` مباشرة في المتصفح (Chrome / Edge) — لا يحتاج خادمًا ولا إنترنت.
للرفع على استضافة ثابتة: ارفع مجلد `app` كما هو.

> التعديلات (دفعات، عقود، شكاوى…) تُحفظ محليًا في متصفح الجهاز نفسه.
> زر «إعادة التعيين إلى بيانات الكشف الأصلية» في الإعدادات يرجع للبذرة.
> النسخة التشغيلية النهائية تُحفظ على خادم بصلاحيات مستخدمين وسجل تعديلات.

## الشاشات

| الشاشة | وظيفتها |
|---|---|
| لوحة المؤشرات | تحصيل الشهر (بمؤشر ▲▼ عن الشهر السابق)، متأخرات + أعمارها، غير الموثَّق، إشغال، تجديدات، تأمينات، إيراد متعاقد، **حالة المباني** (طوابق × وحدات ملونة بحالة الشهر)، تنبيهات، سجل حركة |
| التحليلات | **إنسايتس مكتوبة بالأرقام** (تغير التحصيل، تركّز المتأخرات، مقارنة الكشوف، منحدر الإيراد، الفجوة المعرفية، فاقد الشواغر) + اتجاه التحصيل 12 شهرًا + أعلى المتأخرين + التزام السداد بالمستأجر + متوسط الإيجار بالنوع + توزيع طرق السداد |
| إدخال كشف جديد | **معالج 3 خطوات**: بيانات الكشف ← صفوف الورقة (وحدة+مستأجر+عقد بجدول سنوات تلقائي) ← تفريغ علامات ✓/✗ في المصفوفة. وزر «+ إدخال» أعلى كل شاشة للعمليات السريعة |
| مصفوفة التحصيل | نفس جدول الورقة (وحدات × شهور بالمبنى) — الضغط على الخلية يسجّل دفعة كاملة، وعمود متأخرات لكل صف، و**وضع تفريغ كشف** (النقر يقلّب ✓/✗/مسح) لتفريغ أي ورقة جديدة بسرعة |
| الوحدات | بطاقات بالمبنى — الحالة محسوبة من العقود (مؤجَّرة / منتهية بلا تجديد / بلا عقد / شاغرة) |
| العقود | **خط زمني (جانت)** بخط «اليوم» + جدول + معالج عقد جديد (سنوات تلقائية، يوم استحقاق، صيانة، ض.ق.م، تأمين) |
| المستأجرون | أرصدة متأخرات لحظية + النوع (فرد/شركة) + بيانات تواصل |
| الشكاوى | سجل بالتصنيف والتكلفة ومن يتحمّلها وزمن الإغلاق |
| جودة البيانات | 25 ملاحظة موثَّقة من تفريغ الكشف — التناقضات والفجوات بنصّها الأصلي وقرار تفسيرها |
| الإعدادات | الافتراضات المعلنة + **إدارة المباني/الكشوف** + حذف البيانات التوضيحية + تصدير CSV + إعادة تعيين |

## تفريغ كشف ورقي جديد (زي «سكرية») — الخطوات

1. الإعدادات ← «كشف/مبنى جديد» (الاسم والمنطقة).
2. الوحدات ← أضف وحدات المبنى (النوع والدور اختياريان).
3. العقود ← «عقد جديد» لكل صف في الورقة — جدول السنوات يتولّد تلقائيًا من قيمة السنة الأولى ونسبة الزيادة.
4. مصفوفة التحصيل ← فعِّل «وضع تفريغ كشف» وقلّب خلايا الشهور ✓/✗ زي الورقة بالظبط.
5. أي خانة الورقة ساكتة عنها سيبها فاضية — النظام يعلّمها «غير موثَّق» بدل ما يخمّن.
6. بعد التفريغ: راجع شاشة جودة البيانات واقفل الأسئلة المفتوحة مع المالك واحدة واحدة.

## القواعد الحاكمة في المنطق

1. **الحالة محسوبة لا مكتوبة** — «متأخر» نتيجة مقارنة استحقاق بسداد، ليست خانة تُملأ.
2. **النظام يفرّق بين «متأخر مؤكَّد» (✗) و«غير موثَّق» (خانة فاضية داخل تغطية الكشف)** — الورق لا يفرّق بينهما.
3. **قيمة الإيجار مربوطة بسنة العقد** لا بالسنة الميلادية؛ الشهر المقطوع بين سنتين يُحسب باليوم.
4. **التجديد عقد جديد** مربوط بسابقه — لا تعديل على القديم.
5. **كل افتراض مُعلَن**: أساس الإيجار (شهري؟) غير محسوم مع المالك — لافتة تحذير ظاهرة حتى يُحسم من الإعدادات، والقيم المقدَّرة (+10٪) معلَّمة بـ ≈ في كل الشاشات.

```
├── index.html        هيكل الصفحة
├── css/app.css       نظام التصميم (RTL، وضع فاتح)
└── js/
    ├── seed.js       بذرة بيانات الكشف + سجل جودة البيانات (22 بندًا)

    ├── charts.js     رسوم SVG (بلا مكتبات)

```

بلا أي تبعيات خارجية — يعمل من `file://` ومن أي استضافة ثابتة.
